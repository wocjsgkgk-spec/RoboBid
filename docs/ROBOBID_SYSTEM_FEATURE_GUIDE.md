> **문서 버전**: v2.0 Enterprise BidOps  
> **최종 갱신일**: 2026-09-04

## 1. 개요 (Executive Summary)

RoboBid AI는 단순 공모 검색기나 투찰가 계산기 수준을 넘어, **공공입찰·정부지원사업 수주 전 주기(Life Cycle)를 통합 관리하는 B2B BidOps 엔터프라이즈 운영체제**로 전면 진화했습니다.

외부 API 연동 전 단계에서도 기업 실무자가 매일 아침 로그인하여 마감 업무를 점검하고, 공모를 발굴·분석하고, 팀원들과 적격성 검토 및 GO/NO-GO 의사결정을 내리고, 필수 증빙 라이브러리를 재활용하며, 마감 전 결격 사유를 원클릭으로 검증할 수 있는 **완결형 내부 제품(Internal Product)**을 완성했습니다.

```
[ 공모 발굴 (02) ] ──> [ 검토 파이프라인 (03) ] ──> [ RFP 분석 & 변경비교 (04) ]
                                                            │
[ 결과 학습 (10) ] <── [ 제출·마감 통제 (06) ] <── [ 제안서 & 증빙 매칭 (05/08) ]
```

## 2. 업무 중심 Information Architecture (IA)

기존의 단순 나열식 메뉴를 폐기하고, 공공사업 실무자의 하루 일과와 주간 입찰 업무 흐름에 맞춘 **3개 레이어(업무, 지식·자산, 지원)**로 재편했습니다.

### [업무 (Operations)] - 매일 수행하는 수주 파이프라인
- **01 오늘 (`/today`)**: 30초 내 즉각 조치 가능한 일일 BidOps 작전 상황실 (오늘 마감 공모, 미결정 의사결정, 오늘의 할 일, 고적합 추천 공모, 퀵 도구)
- **02 공모 (`/opportunities`)**: 9개 공모 유형(R&D, 실증, 보조금, 지자체, 국비, 구매, 용역, PPP 등) 통합 탐색, 직접 수동 등록, CSV 대량 업로드, 14단계 상태 관리, 칸반/테이블 뷰
- **03 검토 파이프라인 (`/pipeline`)**: 발굴 → 관심 → 적격성 → 기술검토 → 사업성검토 → 지원결정 5단계 퍼널 칸반, 1-클릭 단계 전진, 담당자 배정, GO/HOLD/NO-GO 의사결정 모달
- **04 RFP 분석 (`/rfp`)**: RFP 요건 추적 매트릭스(RTM), 발주처 핵심 요구사항 자동 분류, **수정공고 변경 비교(Revision Diff) 뷰어**
- **05 제안서 (`/proposals`)**: 공공사업 표준 4단 구성 제안서 작성, 블록형 생성기, 역량·증빙 실시간 바인딩
- **06 제출·마감 (`/submissions`)**: 최종 제출 통제 센터, 6대 필수 체크리스트, 미충족 시 제출 차단, 대표자 최종 승인 서명, 투찰 영수증/증빙 아카이빙

### [지식·자산 (Assets & Tools)] - 기업 수주 경쟁력의 원천
- **07 회사역량 (`/vault`)**: 기업 실적, 기술 TRL(TRL 7 기반), 투입 인력, 특허 등 수주 자산 금고
- **08 자료·증빙 (`/evidence`)**: 사업자등록증, 국세·지방세 완납증명, 특허등록증, 실적증명원 등 공공서류 라이브러리, 유효기간 D-30 알림, 스마트 재활용 추천
- **09 입찰도구 (`/tools`)**: 나라장터 15개 복수예비가격 시뮬레이터(A값 반영), 100점 만점 적격심사 자가진단표, R&D 민간부담금(현금/현물) 매칭 계산기
- **10 성과·학습 (`/learning`)**: 낙찰/탈락 원인 사후 분석(AAR), 발주처별 성향 및 심사 피드백 데이터 자산화

### [지원 (Support & Collaboration)]
- **RoboBid AI (`/ai`)**: 실시간 공공입찰 전문 코파일럿 (프롬프트 템플릿 내장)
- **업무·협업 (`/tasks`)**: 공모/제안서 연계 태스크 칸반, 우선순위 및 마감일 추적
- **알림 센터 (`/notifications`)**: D-Day 긴급 알림, 파이프라인 변동, 공고 변경 알림
- **시스템 설정 (`/settings`)**: DEMO/실데이터 전환 토글, 로컬 JSON 전체 백업/복원, 기업 기본 프로필 설정

## 3. 핵심 신규 및 고도화 기능 상세

### ① 30초 내 상황 파악 가능한 "오늘(Today)" 작전실 (`/today`)
- 무의미한 통계 차트를 배제하고 즉각 조치해야 할 Action Item 위주 배치:
  - **D-Day 임박 공모**: D-1, D-3, D-7 마감 직전 긴급 건 즉시 확인
  - **대기 중인 의사결정**: GO / HOLD / NO-GO 결정이 보류된 공모 목록 및 1-클릭 결정
  - **오늘의 할 일 (Tasks)**: 체크박스 토글로 즉시 완료 처리 가능한 태스크 큐
  - **오늘의 추천 공모**: 기업 프로필(TRL 7, AI 소프트웨어) 기반 90% 이상 고적합 공모 제시
  - **업무 도구 퀵 런처**: 투찰 계산기, 적격심사, 현금/현물 계산기 즉시 실행

### ② 5단계 검토 파이프라인 (`/pipeline`)
- `발굴(DISCOVERY) → 관심(INITIAL_INTEREST) → 적격성(ELIGIBILITY_REVIEW) → 기술검토(TECH_EVALUATION) → 사업성검토(BUSINESS_EVALUATION) → 지원결정(DECIDED)`
- 단계별 1-클릭 전진 (`advanceStage`), 일괄 이동 (`bulkAdvance`), 검토 담당자 배정 기능.
- 지원결정 단계 진입 시 GO/HOLD/NO-GO 의사결정 모달과 자동 연동.

### ③ 공모 직접 등록 및 CSV 대량 가져오기 (`/opportunities`)
- 외부 API 키가 없어도 공모를 등록할 수 있는 직관적인 **수동 공모 등록 모달**:
  - 공고명, 발주처, 공모 유형(9종), 추정가격, 공고일/마감일, 지원자격, 원문 링크 입력.
- **CSV 대량 가져오기**: 나라장터 등에서 다운로드한 CSV 목록을 드래그앤드롭하여 한 번에 파이프라인으로 적재.
- 데이터 출처 뱃지(`DEMO`, `USER_INPUT`, `IMPORTED`, `API`) 명확한 표시.

### ④ RFP 요건 추적 매트릭스 & 수정공고 변경 비교 (`/rfp`)
- **요건 추적 매트릭스 (RTM)**: 기술, 실적, 재무, 인력, 보안 등 발주처 요구사항을 체크리스트로 분해하고 제안서 섹션과 매핑.
- **수정공고 변경 비교 (Revision Diff)**: 정정공고 발생 시 최초 공고와 변경 공고의 마감일 연장, 참가자격 완화, 과업 변경 사항을 좌우 Diff로 시각화하여 탈락 위험 선제 방지.

### ⑤ 6대 안전장치 제출·마감 통제 센터 (`/submissions`)
- **Zero-Auto-Submission 원칙**: AI 자동 제출 불가, 반드시 사람의 최종 검토 및 대표자 승인 필요.
- **6대 필수 체크리스트**:
  1. 제안서 최종본 승인 및 해시 생성
  2. 가격투찰 금액 적격성 검증 (A값/예가 범위 내)
  3. 필수 증빙서류 100% 구비 (국세/지방세 완납, 인감증명 등)
  4. 입찰보증금 또는 지급각서 등록 확인
  5. 지문보안토큰 또는 공동인증서 갱신 상태 확인
  6. 담당 실무자 최종 크로스 체크
- 미충족 시 제출 완료 버튼 자동 비활성화(Disabled) 및 결격 사유 경고 출력.
- 최종 승인 시 투찰 영수증 발행 및 감사 로그 영구 보관.

### ⑥ 공공 증빙 라이브러리 (`/evidence`)
- 6대 카테고리(`법인·인허가`, `지식재산권`, `인증·지정`, `실적증명`, `재무제표`, `제품·기술소개서`) 분류.
- 공공입찰 전용 유효기간 만료 D-30, D-7 사전 경고 알림.
- 공모별 필요 증빙 자동 매칭 및 제안서 스마트 재활용 추천 점수(0~100) 산출.

### ⑦ 3대 공공입찰 전문 도구 허브 (`/tools`)
1. **나라장터 복수예비가격 시뮬레이터**:
   - 기초금액 기준 15개 복수예비가격(±3% or ±2%) 무작위 추첨 4개 평균 산출.
   - A값(국민연금, 건강보험, 산재보험 등) 반영된 실제 투찰 하한가 정밀 계산.
2. **100점 만점 적격심사 자가진단표**:
   - 경영상태(신용평가등급), 수행실적, 기술능력, 신인도(가산점/감점) 배점 시뮬레이션.
   - 통과 기준 점수(예: 85점, 95점) 도달 여부 및 부족한 점수 보완 제언.
3. **R&D 민간부담금 매칭 계산기**:
   - 정부지원연구개발비와 기관부담연구개발비(중소기업 기준 현금 10%, 현물 90% 등) 자동 분할 계산.

## 4. 데이터 아키텍처 및 상태 관리

- **TypeScript Strict Zero-Error**: 전체 소스코드에 대한 완벽한 타입 안전성 보장.
- **Zod 스키마 검증**: 모든 도메인 엔티티(Opportunity, Pipeline, Task, Evidence, Proposal, Submission)에 대해 런타임 유효성 검증 적용.
- **LocalStorage 영속화**: 브라우저 로컬 저장소를 기반으로 새로고침 시에도 사용자 입력 데이터, 태스크 완료 상태, 파이프라인 단계 변경이 안전하게 보존됨.
- **데이터 출처 분리**:
  - `DEMO`: 공공입찰 실무 시연용 풍부한 샘플 데이터 (단추 하나로 초기화 가능)
  - `USER_INPUT`: 실무자가 수동 등록한 실제 입찰 건
  - `IMPORTED`: CSV 등으로 일괄 반입한 데이터
  - `API`: 향후 공공데이터포털 등 연결 시 활용할 데이터 슬롯
- **완전 로컬 백업**: `/settings`에서 JSON 파일로 전체 시스템 상태 원클릭 내보내기/가져오기 지원.

## 6. 향후 외부 API 연동 로드맵

현재 로컬 데이터 계층은 추후 외부 API 연동 시 코드 수정 없이 어댑터(Adapter)만 교체할 수 있도록 모듈화되어 있습니다.

1. **Phase 3 (예정) 1순위 연동 대상**:
   - **조달청 나라장터 (KONEPS) 공공데이터포털 Open API**: 입찰공고정보서비스 (용역/물품/공사 입찰공고 실시간 수집 및 개찰결과 조회)
2. **2순위 연동 대상**:
   - **중소벤처기업부 기업마당 / K-Startup API**: 정부지원사업 및 창업지원 공고 수집
3. **3순위 연동 대상**:
   - **범부처통합연구지원시스템 (IRIS) / TIPA (중소기업기술정보진흥원)**: 국가 R&D 과제 공고 수집
